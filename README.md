# Mini BUH

Десктопний CRM для бухгалтерів і податкових брокерів. Побудований на **NeutralinoJS + Vite + Vue 3 + Dexie (IndexedDB) + Naive UI** — не потребує бекенду, всі дані зберігаються локально.

## Можливості

### Клієнти
- Ведення бази клієнтів: фізичні особи, ФОП, юридичні особи
- Статуси: активний, лід, неактивний
- Теги, журнал взаємодій, архівування
- Окреме поле ідентифікаційного коду: ІПН/РНОКПП (10 цифр) для фіз/ФОП, ЄДРПОУ (8 цифр) для юросіб — з валідацією та пошуком за кодом
- Групи клієнтів: окрема сторінка набору клієнтів до групи (кнопка «Клієнти» у списку груп)

### Податковий модуль
- Налаштування податкового профілю клієнта (загальна / спрощена система, групи ФОП, ПДВ, ЄСВ тощо)
- Автоматична генерація звітів на основі правил
- Дашборд звітів (стартова сторінка застосунку) з груповою навігацією по місяцях
- Звіт видимий протягом усього вікна здачі — від місяця початку здачі до місяця крайнього терміну (для річних — з січня)
- Панель фільтрів: пошук за клієнтом, категорії, статуси, група + кнопка скидання всіх фільтрів
- Тег групи в заголовку клієнта з кліком-фільтром
- Статуси звітів: очікує / зв'язались / подано / ігноровано

### Білінг
- Прайс-лист послуг з повною історією змін
- Автоматичне формування чернетки рахунку з карточки податків клієнта
- Редагування складу рахунку: ввімк/вимк позиції, коригування сум, ручні послуги
- Дата рахунку (довільна дата для чернетки; період виводиться з дати)
- Статуси рахунку: чернетка → підтверджено → оплачено
- Скасування оплати: видаляє повʼязаний платіж і повертає рахунок у «Підтверджено»
- Друк рахунку за шаблоном документів (типовий шаблон — однією кнопкою, інші — через меню)

### Документи / шаблони
- Конструктор шаблонів документів з живим переглядом (рахунки, квитанції платежів, картки клієнтів, групи)
- Текстовий рушій (mini-Handlebars): підстановка токенів `{{ … }}`, фільтри (`money`, `date`, `upper`, …), умови `{{#if}}`, цикли `{{#each}}`
- Markdown-розмітка тіла (заголовки, списки, жирний/курсив, посилання) з екрануванням HTML
- Палітра токенів генерується автоматично зі схеми даних (базова сутність + повʼязані таблиці)
- Кілька шаблонів на сутність, вибір типового; керування у Налаштування → Шаблони

### Платежі
- Реєстрація платежів до рахунків
- Контроль заборгованості

## Технологічний стек

| Шар | Технологія |
|-----|-----------|
| Рантайм | [NeutralinoJS](https://neutralino.js.org/) |
| Збірка | Vite 6 |
| Фреймворк | Vue 3 (Composition API) |
| Стан | Pinia |
| Роутер | Vue Router 4 (hash history) |
| БД | Dexie 4 (IndexedDB) |
| UI | Naive UI + @vicons/ionicons5 |
| Валідація | Valibot + VeeValidate |

## Структура проекту

```
src/
├── views/          # Клієнти, теги, налаштування
├── components/     # Спільні компоненти
├── modules/
│   ├── tax/        # Податковий модуль (Vue Plugin)
│   ├── billing/    # Модуль рахунків (Vue Plugin)
│   ├── payments/   # Модуль платежів (Vue Plugin)
│   └── documents/  # Конструктор шаблонів документів (Vue Plugin)
├── stores/         # Pinia stores
├── db/             # Dexie ініціалізація
├── router/         # Vue Router
└── services/       # Бізнес-логіка
```

Кожен модуль — незалежний Vue Plugin, підключається в `main.js`, не змінює спільний код.

## Встановлення та запуск

### Вимоги

- Node.js 18+
- [Neutralino CLI](https://neutralino.js.org/docs/getting-started/your-first-neutralinojs-app): `npm install -g @neutralinojs/neu`

### Встановлення

```bash
npm install
neu update
```

### Режими запуску

```bash
# Браузер (для розробки UI)
npm run dev

# Десктоп (NeutralinoJS)
npm run neu:dev
```

### Збірка

```bash
# Збірка для всіх платформ
npm run neu:build

# Пакування (Linux)
npm run neu:package-linux

# Пакування (Windows)
npm run neu:package-win

# Пакування (macOS)
npm run neu:package-mac
```

Готові бінарники з'являться в `dist/`.
